# 🛒 Retail Sales Analysis with SQL

A comprehensive SQL-based retail analytics project designed to transform raw transactional sales data into actionable business insights regarding customer behavior, product performance, revenue trends, and seasonal purchasing patterns using PostgreSQL.

## 📌 Overview

* **Author:** Omkar Pardeshi
* **Tech Stack:** SQL (PostgreSQL), GitHub
* **Project Type:** Open Source
* **Duration:** 2 Weeks
* **Impact:** Built 10+ business-driven SQL queries to analyze retail sales, customer demographics, and product performance

## 🚀 The Challenge

Retail businesses generate high volumes of transactional sales records, but raw data alone fails to explain performance drivers. Key strategic questions—such as identifying top-performing product categories, high-revenue customers, peak sales periods, and demographic purchasing differences—require a structured database query approach.

The goal of this project was to clean and analyze a retail dataset using SQL and convert transactional records into meaningful insights that drive customer targeting, inventory management, and promotional strategy decisions.

## 🛠️ Solution & Technical Implementation

The project covers an end-to-end SQL analytics pipeline, spanning data cleaning, validation, exploratory data analysis (EDA), and targeted business reporting.

### 1. Data Cleaning & Validation
* Utilized PostgreSQL to inspect data integrity, filter out incomplete records, and validate key schema attributes: `transaction_id`, `sale_date`, `customer_id`, `category`, `quantity`, `price_per_unit`, `cogs`, and `total_sale`.

### 2. Advanced SQL Query Design
* Implemented core SQL analytical constructs including aggregations, grouping, Common Table Expressions (CTEs), `CASE` logic, window functions, and ranking methods.
* Engineered queries to solve key analytics tasks:
  * Total revenue and quantity sold per product category.
  * Average customer age distribution segmented by product category.
  * Identification of high-value transactions above specific thresholds.
  * Top customers ranked by total revenue contribution.
  * Monthly and yearly sales trend analysis to isolate best-selling periods.

### 3. Business-Focused Analysis
* Formatted query outputs to mirror real-world business scenarios, highlighting category demand, customer spending behavior, and seasonal revenue patterns.

## 📈 Outcome & Key Takeaways

* **Outcome:** Delivered a structured, repeatable SQL analysis framework that streamlines retail performance reporting and supports promotional planning.
* **Key Learning:** Advanced proficiency in PostgreSQL, data cleaning workflows, complex query design, and translating transactional datasets into strategic business recommendations.
